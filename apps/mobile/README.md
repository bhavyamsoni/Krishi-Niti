# KrishiNiti Farmer Mobile App (Flutter)

Offline-first multilingual precision agriculture mobile application built with Flutter, SQLite, and local Text-To-Speech (TTS).

## Key Features
- **100% Offline Farmer Workflow**: Create fields, record soil tests, calculate fertilizer dosages, and record applications without internet.
- **Deterministic Agronomic Engine**: Local Dart port calculates exact NPK dosages, bag requirements, and estimated input costs (₹).
- **Multilingual & Voice-Assisted**: Gujarati (ગુજરાતી), Hindi (हिंदी), and English with 1-tap local device speech playback.
- **Safety & Sustainability**: Color-coded nutrient status, confidence indicator, and over-application warnings.
- **Pre-Seeded Demo Data**: Includes demo Cotton field in Gujarat with pre-populated soil test data for immediate hackathon walkthrough.

## Running the Mobile App
```bash
cd apps/mobile
flutter pub get
flutter run
```
