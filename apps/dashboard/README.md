# KrishiNiti Agriculture Officer Dashboard (Next.js)

Next.js 14 web application transforming distributed field soil tests and fertilizer records into regional intelligence for Agriculture Officers, Extension Directors, and Policy Planners.

## Key Capabilities
- **Privacy-Safe Regional Aggregations**: District, block, and village-level deficiency percentages without exposing any farmer personal identifiable information (PII).
- **Interactive Priority Map**: Color-coded severity clusters (🔴 Critical, 🟡 Moderate, 🟢 Normal).
- **Nutrient Depletion Trends**: Time-series charts analyzing soil nutrient depletion across crop growth stages.
- **Priority Intervention Table**: Exportable village breakdown with recommended agricultural extension directives.
- **Printable Briefs**: Formatted PDF / Print-ready government assessment reports.

## Local Setup
```bash
cd apps/dashboard
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
